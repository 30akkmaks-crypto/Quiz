QuizForge — Викторина (Квиз) на 7 языках
QuizForge — это коллекция из семи независимых реализаций интерактивной викторины, каждая из которых работает на своём языке программирования. Проект создан для демонстрации кроссплатформенного подхода и предоставления удобного инструмента для создания и прохождения тестов с расширенными возможностями.

✨ Уникальные возможности (общие для всех версий)
📚 Обширная база вопросов: более 50 вопросов по различным темам (наука, история, география, спорт, искусство, технологии, кино, литература).

🎯 Множество режимов игры:

Классический режим (10 случайных вопросов)

Режим марафона (все вопросы подряд)

Режим "Своя игра" (выбор категории)

⏱️ Таймер ответа (в некоторых версиях) — ограничение времени на вопрос.

📊 Система подсчёта очков с бонусами за скорость.

🏆 Таблица рекордов (сохранение лучших результатов).

🔄 Перемешивание вопросов для неповторяемости.

📝 Экспорт результатов в текстовый файл/CSV.

🖥️ Интерфейсы:

Командная строка (CLI) с цветным выводом.

Графический интерфейс (GUI) в Python, Java, C#.

Веб-интерфейс в PHP и JavaScript.

Использование (общий синтаксис)
CLI (все версии):

bash
quiz start [--category science] [--questions 10] [--timer 30]
quiz stats
quiz leaderboard
quiz export --output results.csv
Примеры:

Начать викторину из 10 вопросов по науке:

bash
python quiz_forge.py start --category science --questions 10
Показать таблицу рекордов:

bash
go run quiz_forge.go leaderboard
